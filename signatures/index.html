How to add it
  1. Gmail: gear icon > See all settings > General > Signature > Create new. Click in the box, paste, then Save Changes at the very bottom.
  2. Apple Mail: Mail > Settings > Signatures. Add one, untick "Always match my default message font", then paste.
  3. Outlook: Settings > Mail (or Accounts) > Signatures. New signature, paste, Save.
  4. If the photo shows as a broken image, use Copy HTML instead and paste it into the HTML or source view.
